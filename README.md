# Cypress Test Suite — Sauce Demo

Automated end-to-end test suite built with Cypress, covering key user flows on the [Sauce Demo](https://www.saucedemo.com) e-commerce practice site.

## What's covered
- **Login** — successful login, login button visibility, error handling for wrong password, logout
- **Product** — product listing and interaction flows
- **Cart** — add-to-cart and cart validation flows

## Tools
- Cypress
- JavaScript

## Why this exists
Built to practice test automation and strengthen API/UI testing skills alongside manual QA work.
